# Logos e iconos del portafolio

Todos los archivos que carga la página están en `public/icons/`. No se usan CDN,
fuentes de iconos remotas ni solicitudes a terceros para mostrarlos. Los enlaces
de GitHub y LinkedIn llevan a los perfiles, y el de Gmail abre el correo. Sus
imágenes son locales.

| Archivos                                     | Procedencia                                                                                                                                                                                                                                                     |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| La mayoría de los SVG de tecnologías y redes | [SVG Logos / Iconify](https://github.com/gilbarbara/logos), distribuidos mediante `@iconify-json/logos@1.2.14` (CC0). Se copiaron solo los iconos utilizados y se centró el `viewBox` en un cuadrado sin modificar el dibujo.                                   |
| `racket.svg`, `latex.svg`                    | [Simple Icons](https://github.com/simple-icons/simple-icons), paquete `simple-icons@16.32.0` (CC0 para estos dos iconos).                                                                                                                                       |
| `djangorest.svg`                             | [Devicon](https://github.com/devicons/devicon), paquete `devicon@2.17.0`; licencia MIT incluida en `public/icons/DEVICON-LICENSE.txt`.                                                                                                                          |
| `gdscript.svg`                               | [Repositorio oficial de Godot](https://github.com/godotengine/godot/blob/master/modules/gdscript/icons/GDScript.svg); licencia MIT incluida en `public/icons/GODOT-LICENSE.txt`.                                                                                |
| `antigravity.png`                            | [Recursos de prensa de Google Antigravity](https://www.antigravity.google/press), versión a color.                                                                                                                                                              |
| `office.png`                                 | [Imagen de Microsoft Office](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/online/images/office-logo.png) y sus [pautas de uso](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/online/branding). |
| `sql.svg`                                    | Pictograma de base de datos creado para este proyecto: SQL no tiene un logotipo de producto único.                                                                                                                                                              |

`gmail.svg` utiliza la variante multicolor de Gmail del catálogo SVG Logos.
Los SVG de AngularJS, Express, FastAPI, Mongoose, Playwright, Postman, React Router,
SQLite, Vercel y ViteJS también proceden de Devicon. `apacheecharts.svg` procede
de Simple Icons y conserva el color de marca indicado por ese catálogo; su licencia
Apache 2.0 se incluye en `public/icons/APACHE-2.0-LICENSE.txt`. `api.svg` es un
pictograma genérico creado para representar la integración con Bencina en Línea.
`chatgpt.svg` muestra el símbolo de OpenAI como referencia a ChatGPT. Los nombres
que acompañan a cada icono en la página indican la tecnología concreta. Las marcas
siguen perteneciendo a sus respectivos titulares; estos archivos se usan solo para
identificar las herramientas mencionadas en el portafolio.
